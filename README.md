# Set Global Tech

Marketing site for **Set Global Technologies** — a solar and inverter company based in Ilorin, Kwara State.

Customers can compare packages, see installation photos, and request a quote that continues on WhatsApp.

**Repository:** [github.com/david-870/setglobaltech](https://github.com/david-870/setglobaltech)

## What it includes

- Package pages with starting systems
- Quote form (appliances, budget, site inspection) that opens WhatsApp
- Project and crew photo galleries
- Mobile-first layout

## Tech stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 |
| Style | CSS3 |
| Behaviour | JavaScript |
